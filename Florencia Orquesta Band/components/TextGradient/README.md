A gold serif accent for one or two words inside a heading. Hand-written from `src/components/ui/TextGradient.astro`.

Despite the name it is **solid `color-fob-gold`**: the brand bans gradient text, and the component was retuned to match. Keep the name for compatibility with the repo, but don't make it a gradient again.

**Use it** to light the key word of a display line ("Nuestro *Repertorio*"). At most once per view.

**Props**: `children`, `className`. It sets the family to Gloock, so it belongs inside serif headings.
