Lucide icons vendored for `astro-icon` (`lucide--calendar`, `lucide--map-pin`): 24 × 24, 2px stroke, round caps and joins. Every other icon comes from the `lucide-react` package.

Their ink is `currentColor`, so inline them in code and set the color there: `color-fob-gold` beside dates and venues, `color-fob-subtle` for supporting meta. Shown here as images, they render black.
